# [2026-2] 모의투자 포트폴리오 - [18기_박수연]

## 전략
* **전략명:** Box Breakout 52-Week High Strategy (박스권 돌파형 52주 신고가 전략)
* **핵심 로직:** 52주 최고 종가 근처에서 10~120거래일 횡보한 종목이 종가로 신고가를 돌파하는 날 매수하고, 손절 · 익절 · 트레일링 스탑 규칙으로 청산
  * 시장 필터: KOSPI 종가 > 60일 이동평균일 때만 신규 매수
  * 스크리닝: 시총 1,000억 원 이상, 5일 평균 거래대금 30억 원 초과 보통주 / 52주 최고 종가의 95% 이내(매수 대기), 90% 이내(관심) / 횡보 구간 변동폭 40% 이내
  * 청산: 손절 -8%, +20%에서 50% 익절, 최고 종가 대비 -15% 트레일링, 40거래일 시간 청산
  * 포트폴리오: 최대 20종목 × 5% 동일비중, 빈 슬롯은 현금
* **백테스트 (2017-01 ~ 2026-09, 거래비용 반영):** 연환산 수익률 10.2%, 변동성 14.0%, 샤프비율 0.55, MDD -21.9% (KOSPI: 14.1% / 24.3% / 0.54 / -43.9%)
* **카페 링크:** [DART 네이버 카페 전략보고서 게시글](https://cafe.naver.com/f-e/cafes/29307656/articles/1121?boardtype=L&menuid=55&referrerAllArticles=false)

## 파일 설명
* `load_data.py` : DataGuide 6 출력 파일(일자×종목) 로더 및 단위 변환
* `backtest.py` : 백테스트 엔진(`run_close`, 종가 기준), 성과 지표, 최종 파라미터(`FINAL`)
* `run_backtest.py` : 데이터 로드 후 규칙 변형별 백테스트 비교 실행
* `finalize.py` : 최종 전략 백테스트 실행, 성과 차트 및 스크리닝 결과 생성
* `screen_today.py` : 장 마감 후 실행하는 일일 스크리닝(시장 필터 상태, 매수 대기 · 관심 종목 출력)
* `requirements.txt` : 필요 패키지

## 실행 방법
1. DataGuide 6에서 받은 수정주가 · 시가총액 · 5일 평균 거래대금 파일을 `data/raw/`에 `close`, `mcap`, `tv5` 이름으로 저장 (유료 데이터라 저장소에는 포함하지 않음)
2. `python run_backtest.py` → `python finalize.py`
3. 매일 장 마감 후 `python screen_today.py`
