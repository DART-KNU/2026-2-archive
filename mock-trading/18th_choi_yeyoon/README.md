# [2026-2] 모의투자 포트폴리오 - [18기_최예윤]

## 전략
* **핵심 로직:** 저변동성 인핸스드 인덱스 + 3분기 실적 서프라이즈 드리프트(PEAD) 오버레이 틸트
  * 시총 상위 80종목 중 (시총 + 저변동성) 결합점수 상위 40종목으로 코어 구성, 포트 베타 0.90~1.00 타기팅
  * 실적 발표 후 SUE(영업이익 서프라이즈)·EAR(발표일 초과수익)가 모두 상위인 종목은 비중을 소폭(+1%p 이내) 상향
  * 종목·섹터 상한 초과분은 재배분해 항상 만투, 드로우다운 −15% 시에만 70%로 축소
* **카페 링크:** [[19기 전략보고서] 저변동성 강화지수 전략](https://cafe.naver.com/f-e/cafes/29307656/articles/1122?boardtype=L&menuid=55&referrerAllArticles=false)

## 진행 과정 (사전 등록 → 백테스트 → 진단 → 재설계)
과최적화를 막기 위해 매 시도마다 **백테스트 전에** 신호·격자·지정 설정을 문서로 고정했고(`preregistration*.md`), 시도 횟수를 누적해 DSR을 계산했습니다.

| 차수 | 전략 | 설정 수 | 샤프 | MDD | 결과 |
|---|---|---|---|---|---|
| 1차 | PEAD 단독 | 27 | 0.35 | −14.7% | 신호 t=1.48로 비유의, 투자비중 20%로 현금 과다 |
| 2차 | 대형주 코어 + 전술 틸트 | 9 | 0.10 | −40.4% | 분산은 개선, 리스크 오버레이로 투자비중 57%, 반도체 과소 |
| 3차 | 저변동성 인핸스드 인덱스 + PEAD 틸트 | 6 | **0.62** | −34.7% | CAGR 10.5%, 베타 0.67, DSR 0.65 (누적 N=42) |

* 백테스트 기간: 2018-01 ~ 2026-09, 유니버스: 시총 3,000억↑ · 20일 평균 거래대금 100억↑
* 코스피200(+245%)은 세 차례 모두 이기지 못했고, 3차는 목표를 "벤치마크 초과"에서 "통제된 위험 안의 시장 추종"으로 바꿨습니다.

## 파일 설명
* `config.py` : 모든 파라미터 (기간, 유니버스, 신호, 보유기간, 비중, 비용)
* `data_loader.py` : pykrx(가격·시총·업종) + OpenDART(분기 실적·공시일) 데이터 수집
* `signals.py` : SUE, EAR, 섹터 내 PIT 백분위, 진입 조건 계산
* `backtest.py` : 일별 시뮬레이션 엔진 + 성과 지표
* `run_backtest.py` : 1차 전략(PEAD 단독) 실행, `--download`로 데이터 수집
* `validate.py` : 1차 27개 설정 전체 백테스트 + PBO(CSCV) · DSR 과최적화 검증
* `diagnose.py` : 이벤트 스터디로 신호 자체의 유효성 진단
* `run_v2.py` : 2차 전략(대형주 코어 + 전술 틸트) 실행 및 검증
* `run_v3.py` : 3차 최종 전략(저변동성 인핸스드 인덱스 + PEAD 틸트) 실행 및 검증
* `demo_data.py` : 합성 데이터 생성기 (코드 동작 확인용, 성과는 의미 없음)
* `preregistration.md`, `preregistration_v2.md`, `preregistration_v3.md` : 차수별 사전 등록 문서
* `results/` : 결과 차트 (루트 = 1차, `validation/` = 1차 검증, `v2/`, `v3/`)
  * `full_cumulative.png` 누적 수익률, `full_drawdown.png` 낙폭, `window_by_year.png` 연도별 10~11월 성과
  * `grid_sharpe.png` 설정별 샤프, `cscv_*.png` PBO 그래프

## 실행 방법
```bash
pip install -r requirements.txt
python run_v3.py --demo                 # 데이터 없이 동작 확인 (합성 데이터)

export DART_API_KEY=발급받은키           # https://opendart.fss.or.kr 무료 발급
python run_backtest.py --download       # 데이터 수집 (처음 한 번, 수 시간 소요)
python run_v3.py                        # 최종 전략 백테스트 → results/v3/
```
> 원본 데이터(`data/`, 약 630MB)와 CSV 결과는 용량 문제로 올리지 않았습니다. 위 명령으로 다시 받을 수 있습니다.
